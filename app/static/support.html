AI Support Agent

Customer-service agent for Northwind Gadgets, a fictional electronics store. It answers from the store's knowledge base with citations, uses tools to look up orders, check refunds and hand off to a human, and refuses unsafe requests.

How it works, and what to try
  1. Guard: checks the message for prompt injection and card numbers, and redacts personal data in logs.
  2. Route: detects intent (question, order status, refund, human) and asks for missing details, like an order number.
  3. Act: searches the knowledge base, or calls a tool against the order system.
  4. Respond: gives a grounded answer with sources. If it isn't confident, it offers a human instead of guessing.
Demo orders: NW-10231 (delivered), NW-10232 (shipped), NW-10233 (final sale), NW-10234 (processing), NW-10235 (delivered 41 days ago).
