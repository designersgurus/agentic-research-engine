Agentic Research Engine

Parallel research → self-verification loop → cited report → outreach with capped follow-ups.

2-minute tour: what to try
  1. Run research with the defaults. The Verification tab shows pass 1 finding a gap, a follow-up research round, then pass 2 stopping clean.
  2. Open Guardrails: token, call and search meters, plus a prompt-injection attempt hidden in a source that was neutralised.
  3. Set the token budget to 1500 and run again. The cap stops the job and returns partial results instead of spending more.
  4. Create an outreach campaign asking for 5 follow-ups. It's capped at 3. Tap Run follow-ups now until contacts close, or Simulate reply to stop one early.
  5. See the full API at /docs.

Demo runs in mock mode with synthetic sources, so it's free to try. With API keys, the same pipeline uses live web search and OpenAI or Anthropic models.
